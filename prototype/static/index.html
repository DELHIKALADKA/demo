Privacy

The video you choose is read on this computer, and the PDF is written on this computer. There is no account, no database and no cloud storage:

  • Local files never leave the machine — decoding and page detection happen using the bundled ffmpeg and the PageSnap engine.
  • PDFs you create are kept in a folder on this computer (the path is shown in the Library) so you can download them again later.
  • Links are fetched from the internet by yt-dlp when you import one. If you never import a link, PageSnap makes no outside requests except loading its own page.
  • Nothing is sent to a third party, and there is no analytics or tracking of any kind.
